# Cplusplus-Program

# Summarize the project and what problem it was solving.

For this project, I created an item-tracking program for the Corner Grocer, which helped track the purchase frequency of their produce items. This was all to aid in the rearranging of their produce section.
  
I created a menu where the user could either a) look up a produce item b) look up its current quantity c) display the entire produce inventory d) add/remove items from the inventory e) save any changes f) print a histogram of produce items and quantities g) exit program when finished. and save any changes made to the file, or exit the program when done.

# What did you do particularly well?

I believe my strongest points in this project were constructing the menu and ensuring effective user-input validation.

# Where could you enhance your code? How would these improvements make your code more efficient, secure, and so on?

Places where I could advance my code are making the user prompts more user-friendly. This would enhance the overall quality and encourage others to wat to engage more with the program.

# Which pieces of the code did you find most challenging to write, and how did you overcome this? What tools or resources are you adding to your support network?

Pieces of the code I found most challenging was constructing the file input function as I kept running into minor errors preventing me from accessing the produce inventory file. After revisiting the ZyBooks reading, I was able to effectively pinpoint and debug any errors, eventually allowing me access to the file through my program.

# What skills from this project will be particularly transferable to other projects or course work?

Skills from this project that I will be able to transfer to other projects/course work are file input/manipulation, creating histograms, the use of maps, and user-input validation.

# How did you make this program maintainable, readable, and adaptable?

I was able to make this program maintainable by using industry best practices such as proper variable naming, use of in-line comments and user-input validation. This made my program readable and easy to use.
